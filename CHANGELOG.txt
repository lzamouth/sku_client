4.0.0-beta12

4.0.0-beta11
- Linux: runs through X11 (XWayland) by default, which resizes smoothly and uses the desktop's title bar; "Window system" option to prefer Wayland on fractional-scale displays
- The addon list fills its area to the bottom
- Development builds are stamped with their commit

4.0.0-beta10
- skunkcrafts_updater.cfg stays in place as the configuration file: aircraft and publishing tools read the version there. Folders converted by earlier betas are migrated back automatically
- The skunkcrafts/ folder inside an add-on now holds only the CRC cache

4.0.0-beta9
- Linux AppImage: the Update button replaces the running AppImage in place and offers to restart, so menu entries and dock icons stay valid

4.0.0-beta8
- User guide (USER_GUIDE.html) shipped with every package
- The updater's own update depot moves to the store CDN; packages are looked up by version, older names still work
- Changelog: bullets and bold version headers; tab-indented entries display cleanly
- The main channel is shown as "Main"
- A tester file with the same name replaces the beta channel it created, whatever its URL, and enabled|false returns to Main

4.0.0-beta7
- A tester file carrying the same depot URL under a new name renames the existing channel instead of adding one
- On a beta channel the depot configuration never renames or moves anything: the production URL always stays

4.0.0-beta6
- The Update / repair buttons light up when an update or a repair is available
- Column titles above the addon list, columns resizable from the header
- The CRC cache moves into the addon folder (skunkcrafts/crc_cache.txt) and follows the addon
- Per-addon files under Output/skunkcrafts/updater are named after the addon folder
- One download per platform: windows.zip, windows-setup.exe, macos.zip, linux.zip, AppImage
- The command-line client fetches its own package (sku-cli.zip)

4.0.0-beta5
- The check for a new version of the updater runs at every start (at most once an hour) and its banner shows on every page

4.0.0-beta4

- Addon list: column titles, columns resizable from the header, channel drop-down per addon (stable in blue, others in yellow)
- Options page laid out proportionally to the window; widths follow the text size
- Packs: members adopt the pack keys published by their depot, so an installed folder joins its pack without reinstalling
- Depot changelog headers are bare version lines again (the aircraft read them)

4.0.0-beta3

4.0.0-beta2
