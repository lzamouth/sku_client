4.2.0
- Public beta channels: a developer can offer a beta to every user from the update server, with no file to hand out; it appears in the Channel column and is followed only if you pick it
- A public channel you removed does not come back; one the developer withdraws disappears, unless you follow it
- sku channels marks the public channels
- The X-Plane installation managed is shown at the top right; with several installations it is a drop-down to switch between them
- The window comes back where it was closed: same monitor, position, size, maximized or not

4.1.2
- A developer's beta file published through the updater is offered as a channel, followed only if you pick it; it no longer asks for an update at every check
- Updates never replace or delete the add-on's own settings file or your ignore list, even if a server lists them
- The status bar tells which channel a beta file became, and has room for longer messages

4.1.1
- Some developers' servers refused the updater: it presents itself as 3.x did again, and asks again without the cache-busting parameters a server rejects (Colimata aircraft, avitab-browser)
- A depot file is no longer refused because the server labels it as a web page; only a real web page is

4.1.0
- Beta channels are kept in the add-on's own skunkcrafts folder; skunkcrafts_updater.cfg, which aircraft read, holds only its usual settings again. Channels set up by 4.0 move there automatically
- A beta channel can be removed from the add-on's details ("Remove channel...", with a confirmation), or with sku remove-channel
- Putting a developer's beta file back no longer adds the same channel twice: the channel already following that beta is updated
- sku channels lists the beta channels of each add-on
- A new log at each start, the three previous ones kept (updater_log.txt.1 to .3); a session's log is never cut, and log viewers following it (klogg, glogg) reload it

4.0.2
- Thranda aircraft whose configuration still names Thranda's former update server are checked and updated again, as with 3.x
- Custom Scenery and Resources/plugins are scanned one level deep, as with 3.x: plugins moved into "(disabled)" are no longer listed
- The add-on list no longer cuts its last row when scrolled to the bottom
- Lighter log: one line per scenery or plugin folder not managed by the updater, no display timing traces

4.0.1
- Windows: connections no longer fail with CRYPT_E_REVOCATION_OFFLINE when the network blocks the certificate revocation server; a revoked certificate is still refused
- A long error message in the updater banner is cut cleanly; hover over it to read it whole

4.0.0
- First release of the rewritten SkunkCrafts Updater: one program for Windows, macOS (Intel and Apple Silicon) and Linux
- No more copy per X-Plane installation: one updater, installed anywhere, finds your X-Plane installations and manages the one you pick
- New interface: addon list with columns, channel per addon, details with files, report, changelog and readme
- Several beta channels per addon, and packs: products made of several folders updated together
- Fast checks thanks to a cache of file checksums; a report for every check and update
- skunkcrafts_updater.cfg stays in place in every add-on; settings and beta files from 3.x are taken over automatically
- The updater keeps itself up to date: a banner shows what changed, Update installs the new version and offers to restart
- Command-line client (sku) for the three systems
- User guide (USER_GUIDE.html) shipped with every download
