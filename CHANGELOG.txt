4.0.1
- Windows: connections no longer fail with CRYPT_E_REVOCATION_OFFLINE when the network blocks the certificate revocation server; a revoked certificate is still refused
- A long error message in the updater banner is cut cleanly; hover over it to read it whole

4.0.0
- First release of the rewritten SkunkCrafts Updater: one program for Windows, macOS (Intel and Apple Silicon) and Linux
- No more copy per X-Plane installation: one updater, installed anywhere, finds your X-Plane installations and manages the one you pick
- New interface: addon list with columns, channel per addon, details with files, report, changelog and readme
- Several beta channels per addon, and packs: products made of several folders updated together
- Fast checks thanks to a cache of file checksums; a report for every check and update
- skunkcrafts_updater.cfg stays in place in every add-on; settings and beta files from 3.x are taken over automatically
- The updater keeps itself up to date: a banner shows what changed, Update installs the new version and offers to restart
- Command-line client (sku) for the three systems
- User guide (USER_GUIDE.html) shipped with every download
